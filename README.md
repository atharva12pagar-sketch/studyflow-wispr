# StudyFlow - Student Study Planner

A simple voice-built student study planner created for the Wispr Flow Shortlisting Task.

## Features
- Add study tasks
- Select subject and priority
- Mark tasks as completed
- Delete tasks
- Filter All / Pending / Completed
- Task counters
- Data saved in browser localStorage
- Responsive design
- No backend or database required

## Tech Stack
- HTML
- CSS
- JavaScript
- Browser localStorage

## Run
Open `index.html` in a browser.

## Wispr Flow
The project is intended to be built and demonstrated using Wispr Flow voice-driven development, as required by the task.
